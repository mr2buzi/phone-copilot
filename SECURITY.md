# Security

The full controller is intended for a single trusted user on loopback. It has no authentication layer and should not be exposed through port forwarding, public tunnels or a shared network interface.

Keep device authorization, provider credentials, contact profiles and message history local. Screenshots, logs, training examples and vector databases can all contain private information.

For a vulnerability, use GitHub's private vulnerability reporting feature when available. Do not attach credentials, chat exports or device captures to a public issue. A public issue can describe a problem using fictional data if no private reporting channel is available.
